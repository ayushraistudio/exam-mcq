# Exam Portal – Online MCQ Examination System

A secure **Online Exam Portal** with **Admin & Student panels**, built using **HTML, CSS, JavaScript, and Firebase**.  
Designed for conducting MCQ-based exams/competitions with real-time control, strict authentication, and automatic evaluation.

🌐 **Live Demo:** https://exam-mcq.netlify.app  
📦 **GitHub Repository:** https://github.com/ayushraistudio/exam

## 🚀 Features

- Secure **Student Login** (Firebase Authentication)
- Separate **Admin & Student panels**
- Admin-controlled **exam start / end**
- **Live exam timer** with auto-submit
- Automatic submission on refresh or exit
- Student-specific exam access
- MCQ-based examination system
- Real-time data handling with Firebase
- Strong security rules applied

## 🧑‍💼 Admin Panel

- Admin authentication
- Create, update, and delete exams
- Add / manage MCQ questions
- Start or stop exams manually
- View student submissions securely

## 🎓 Student Panel

- Login required to access exam
- Exam available only when admin allows
- Live countdown timer
- Auto-submit on time completion
- One-attempt policy
- Direct URL access blocked

## 🔐 Security

- Firebase Authentication
- Firestore Security Rules
- Role-based access (Admin / Student)
- No unauthorized database access
- Exam data protected from tampering

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Firebase
- **Authentication:** Firebase Auth
- **Database:** Firestore
- **Hosting:** Netlify
